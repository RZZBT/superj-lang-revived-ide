# archive/JJ: original files, unmodified

Copied byte-for-byte from the author's old download folder (`Batch download JJ etc/JJ`). Nothing in this directory
has been edited; `MANIFEST.sha256` lists the SHA-256 of each file:

    cd archive/JJ && sha256sum -c ../MANIFEST.sha256

See `docs/LANGUAGE_ARCHAEOLOGY.md` for what these files are and what they show.
`a.out` and `JJexe` are Linux ELF binaries (the compiler and a compiled program); they are kept as evidence and never executed by this project.
